# 运行验证记录

验证日期：2026-11-06。该文件记录实际执行范围，不代表生产级质量评测。

环境说明：以下既有测试结果来自教程编写时的 Windows/Python 3.12 环境。教程运行说明现已按你的 Linux + Miniconda/aienv + Python 3.12 调整，但尚未在你的 Linux 机器上重新执行测试，不将原结果改写为 Linux 实测。

## 已实际执行

- 使用环境中已有的 Python 3.12 运行代码；主项目无第三方 Python 依赖。
- 运行 `python -B -m unittest -v`：9 项测试全部通过。
- 运行 BM25 建库：5 篇文档、5 个文本块。
- 运行 8 条问题的 BM25 检索评测，其中 7 条有答案、1 条无答案。

参数：`chunk_size=600`、`overlap=100`、`candidate_k=10`、`top_k=3`。

| 指标 | 实测值 | 口径 |
|---|---:|---|
| hit 均值 | 1.0000 | 7 条有答案题，文档级 |
| recall 均值 | 1.0000 | 7 条有答案题，文档级 |
| reciprocal_rank 均值 | 1.0000 | 去重来源后的首个相关文档排名 |
| source_precision 均值 | 0.3810 | 命中来源数 / 实际返回的不同来源数 |

这些数据来自极小的教学语料。不能推断复杂长文、不同知识库或生成回答也达到同样效果。单次运行的耗时不作为性能基准。

无答案题“年度套餐多少钱”仍召回了套餐、错误码与退款文档。套餐页只说明未列年度价格，因此应拒答具体年价；检索分数本身无法证明证据充分。

## 测试覆盖

1. 切分区间、边界、尾部覆盖与非法 overlap。
2. 向量归一化、余弦等价计算与异常维度。
3. RRF 手算例子的排序。
4. 中文词项与精确错误码检索。
5. 建库、查询、删除文件后完整重建。
6. 模拟 Embedding→混合检索→生成→引用的数据流。
7. Embedding 条数错误、缺少向量和非法候选数量。
8. 证据预算、未知引用及空证据拒答。
9. 文档级指标去重与无答案题排除。
